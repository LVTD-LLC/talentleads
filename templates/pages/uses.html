Technology

The stack behind TalentLeads.

TalentLeads runs on a simple, durable Django stack with enough operational tooling to support the product without turning the codebase into platform theater.

I run multiple projects at the same time, and reliable technology keeps the product maintainable. Here is what this project uses:

  • OSIG: OG image generation.
  • Statushen: Status page monitoring.
  • Sentry: Error tracking and performance monitoring.
  • Hetzner: Cloud infrastructure.
  • Buttondown: Newsletter infrastructure.
  • Django: Backend web framework.
  • Django Q2: Background tasks and scheduling.
  • CapRover: Deployment and server management.
  • GitHub: Version control and collaboration.
  • Redis: Caching and queue support.
  • PostgreSQL: Primary database.
  • Anthropic: AI capabilities.
  • Replicate: Model deployment.
  • OpenTelemetry: Observability data.
  • StimulusJS: Focused frontend interactivity.
  • WhiteNoise: Static file serving.

Questions about the stack can go to contact@gettalentleads.com.
